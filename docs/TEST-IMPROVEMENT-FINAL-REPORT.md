## 七、学到的经验

### 🎯 核心原则

1. **完全隔离优于部分隔离**
   - ✅ beforeEach + afterEach
   - ❌ 仅 beforeAll 或仅 afterAll

2. **多层隔离非冗余**
   - 数据库隔离 ≠ 文件隔离 ≠ 服务隔离
   - 各层需要独立策略

3. **清理失败不能阻塞测试**
   - 使用 try-catch 包装清理
   - 记录但不抛出异常

4. **隔离支持灵活执行**
   - 单独运行 ✅
   - 多次运行 ✅ (结果一致)
   - 并行运行 ✅
   - 任意顺序 ✅

5. **隔离提升可理解性**
   - 每个测试自成一体
   - 不需要看其他测试
   - 容易调试和维护

### 🔍 常见陷阱

| 陷阱 | 症状 | 修复 |
|------|------|------|
| 无隔离 | 间歇性失败 | 添加 beforeEach/afterEach |
| 清理异常 | 测试中断 | try-catch 包装 |
| 部分隔离 | 仍有污染 | 完整隔离四层 |
| 共享状态 | 顺序依赖 | 每测试刷新状态 |
| 遗漏场景 | 缺乏覆盖 | 并发+边界+生命周期 |

### 💡 最佳实践

```typescript
// ✅ DO
beforeEach(() => { resetState() })
afterEach(() => { resetState() })
try { cleanup() } catch(e) { log(e) }

// ❌ DON'T
beforeAll(() => { resetState() })  // 太晚了
throw new Error('cleanup failed')  // 阻塞测试
function cleanup() { risky() }     // 无保护
```
